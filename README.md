## About

Car rental mock site created for Programming on the Internet (UTS subject) Assignment 2.
Ran locally using Apache.

## How to run
1. Install XAMPP and open the XAMPP Control Panel.
2. Copy this project folder into XAMPP's htdocs folder (see below).
3. Name the folder exactly poti assignment 2. The site's links and scripts use the path /poti assignment 2, so it will not load correctly under a different name.
4. Start Apache in the XAMPP Control Panel.
5. Open http://localhost/poti%20assignment%202/ in your browser.

Note: bookings are written to assets/data/orders.json and assets/data/cars.json, so these files need to be writable by the web server.
